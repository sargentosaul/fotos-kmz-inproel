Fotos a KMZ - Inproel

Recorrido fotográfico para Google Earth a partir de fotos con GPS (dron o celular).

Las fotos se procesan en tu computador, no se suben a internet.

Usa una carpeta por vuelo para que la línea del recorrido tenga sentido. Si eliges una carpeta con subcarpetas, cada subcarpeta tendrá su propia línea.

1. Crear KMZ

o arrastra aquí la carpeta o las fotos (JPG / PNG)

.kmz

2. Ver y descargar fotos de un KMZ

Abre un KMZ hecho con esta herramienta (o con el programa FotosAKMZ.exe) para ver todas sus fotos y descargar la que necesites.
